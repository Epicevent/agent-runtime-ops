# Shared Document Tools

Public, non-secret document tooling included in wrapper images.

The HWP/HWPX contract follows `openclaw-nas-agent-baseline`:

- `openclaw-hwp-text`
- `read-hwp`
- `hwp-read`
- `hwp2txt`
- `openclaw-document-tools`

Do not use `pandoc` for `.hwp` files. Use `openclaw-hwp-text` before saying
that HWP/HWPX content is unsupported.

Do not place customer documents, credentials, API keys, or server state here.
