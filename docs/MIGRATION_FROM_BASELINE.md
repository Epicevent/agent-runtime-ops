# Migration From Baseline

`openclaw-nas-agent-baseline` is legacy after this repository becomes the
operating standard.

Carry forward:

```text
customer/runtime/data group model
NAS grant idea
image digest rollout idea
secret redaction
admin visibility
```

Do not carry forward:

```text
large shell wrapper culture
compose heredocs inside shell
file-exists compose auto-include
ad-hoc NAS compose repair path
one-off helper scripts
check commands that mutate state
```
